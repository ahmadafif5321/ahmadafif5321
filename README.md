## Featured projects

### [Whisper-Malay](https://github.com/ahmadafif5321/Whisper-Malay)
Android voice dictation for Bahasa Melayu and Manglish, running Whisper models
fully on-device via sherpa-onnx — nothing leaves the phone. The latest version
embeds dictation directly in an Android keyboard (IME), so it needs no
accessibility service and works in banking apps.

### [GoogleMapScrapper](https://github.com/ahmadafif5321/GoogleMapScrapper)
Google Maps review intelligence platform: a 24/7 systemd collector, Dockerized
scraper, DuckDB incremental merge, NLP sentiment analysis (XLM-RoBERTa), and a
Streamlit dashboard. Currently at 2.2M+ reviews across 17,900+ places, and growing.

### [Powershell-Citrix](https://github.com/ahmadafif5321/Powershell-Citrix) & [Powershell-Server](https://github.com/ahmadafif5321/Powershell-Server)
Real-world operations scripts from managing production Citrix and Windows
Server environments — the day-job automation, in public.

### [manusiawi](https://github.com/ahmadafif5321/manusiawi)
A Claude skill that strips AI-writing patterns from Malaysian Bahasa Melayu
text: 32 BM patterns, Indonesian intrusion detection, and 24 English patterns.
